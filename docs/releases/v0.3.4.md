# Grapefruit 0.3.4 Preview

Grapefruit 0.3.4, menüyü bağımsız klavye kısayollarından ayıran ve yalnızca
gerçek dosya sürüklemelerine bağlayan bir Windows/Linux düzeltme sürümüdür.

## İndir

- **Windows 10/11 x64:** `Grapefruit_0.3.4_x64-setup.exe`
- **Ubuntu/Debian amd64:** `Grapefruit_0.3.4_amd64.deb`

## Düzeltmeler

- `Ctrl+Shift+F` ve `Ctrl+Shift+A` global kısayollarını, ilgili Tauri eklentisini
  ve Wayland portal kaydını tamamen kaldırma
- Menüyü Windows'ta yalnızca Explorer veya masaüstünden başlayan, gerçek Shell
  dosya seçimi doğrulanmış sürüklemelerde Shift/Ctrl ile açma
- Windows 11 masaüstü Shell görünümünü `CSIDL_DESKTOP` üzerinden sorgulayarak
  masaüstündeki seçili dosyayı sürükleme başında yakalama
- PDF ve belge dönüşümlerinin `.file-formatter-*` çalışma klasörlerini kaynak
  klasörde göstermemesi için ara çıktıları sistem geçici dizininde hazırlama
- Dönüşüm tamamlanmadan hedef dosyayı göstermeme ve farklı disk durumunda mevcut
  çıktının üzerine yazmadan güvenli kopyalama
- Uygulama durum metnini global kısayol yerine dosya sürükleme entegrasyonunu
  gösterecek şekilde güncelleme

## Linux kurulumu

```bash
sudo apt install ./Grapefruit_0.3.4_amd64.deb
```
