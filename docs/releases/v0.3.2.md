# Grapefruit 0.3.2 Preview

Grapefruit 0.3.2, Windows masaüstü ve Explorer'daki dosya sürüklemelerinin
güvenilir biçimde tanınmasına odaklanan bir düzeltme sürümüdür.

## İndir

- **Windows 10/11 x64:** `Grapefruit_0.3.2_x64-setup.exe`
- **Ubuntu/Debian amd64:** `Grapefruit_0.3.2_amd64.deb`

## Düzeltmeler

- Windows masaüstü foreground pencere olmadığında da sürükleme kaynağını
  imlecin altındaki kök pencereden tanıma
- Windows 11 sekmeli Explorer'da aynı çerçevedeki kayıtları tarayıp gerçek
  dosya seçimini bulma
- Seçimi sürükleme eşiği aşılır aşılmaz kaynak pencerede yakalama;
  imleç başka pencereye taşındıktan sonra Shift/Ctrl kullanabilme
- Tarayıcı, editör ve terminaldeki metin sürüklemelerini reddetmeye devam etme
- Reddedilmiş bir sürüklemede tuş basılı tutulurken tekrar tekrar tetiklemeyi
  engelleme

## Linux kurulumu

```bash
sudo apt install ./Grapefruit_0.3.2_amd64.deb
```
