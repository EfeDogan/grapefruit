# Grapefruit 0.3.0 Preview

Grapefruit'in Windows ve Linux için ilk indirilebilir preview sürümü.

## İndir

- **Windows 10/11 x64:** `Grapefruit_0.3.0_x64-setup.exe`
- **Ubuntu/Debian amd64:** `Grapefruit_0.3.0_amd64.deb`

## Öne çıkanlar

- Dosya sürüklerken Shift ile dönüşüm, Control ile dosya işlemleri menüsü
- İmlecin yanında açılan şeffaf dairesel menü
- Görsel, video, PDF, belge ve sunum dönüşümleri
- Yolu kopyalama, kopyalama, taşıma, klasörde gösterme ve terminal işlemleri
- Windows paketinde gömülü FFmpeg ve Poppler araçları
- Linux paketinde GNOME Shell ve Nautilus bütünleştirme dosyaları

## Linux kurulumu

`.deb` paketi gerekli dönüşüm araçlarını paket bağımlılıkları olarak kurar.
GNOME Shell uzantısını kurulumdan sonra kullanıcı hesabında etkinleştir:

```bash
sudo apt install ./Grapefruit_0.3.0_amd64.deb
gnome-extensions enable grapefruit@io.github.efedogan
nautilus -q
```

GNOME Shell yeni sistem uzantısını henüz görmüyorsa oturumu kapatıp yeniden aç.
