# Grapefruit 0.3.3 Preview

Grapefruit 0.3.3, gerçek Windows testinde görülen masaüstü algılama, başlangıç
geri bildirimi ve dönüşüm araçlarının konsol penceresi açması sorunlarını
gideren bir düzeltme sürümüdür.

## İndir

- **Windows 10/11 x64:** `Grapefruit_0.3.3_x64-setup.exe`
- **Ubuntu/Debian amd64:** `Grapefruit_0.3.3_amd64.deb`

## Düzeltmeler

- Windows masaüstündeki dosya seçimini sürükleme görüntüsü kaynak pencereyi
  kapatmadan önce, ilk fare basışında yakalama
- Eşik anındaki yedek sorguyu imlecin güncel konumu yerine sürüklemenin kaynak
  konumunda yapma
- FFmpeg, Poppler ve LibreOffice'i Windows'ta görünür Komut İstemi penceresi
  oluşturmadan çalıştırma
- İkinci kez başlatıldığında yeni izleyici oluşturmak yerine çalışan Grapefruit
  penceresini açan tek-örnek koruması
- Açılışta Windows bildirimi gösterme ve tray ikonunu pakete gömülü Grapefruit
  ikonu ile açıkça oluşturma
- Tarayıcı ve editör tıklamalarında Explorer otomasyonuna hiç bağlanmadan çıkma

## Linux kurulumu

```bash
sudo apt install ./Grapefruit_0.3.3_amd64.deb
```

## Doğrulama

- TypeScript ve Vite production derlemesi başarılı

- Linux Debian paketinin sürümü `0.3.3`, mimarisi `amd64` olarak doğrulandı
