# Grapefruit 0.3.1 Preview

Grapefruit 0.3.1, sistem genelindeki sürükleme menüsünü Linux ve Windows'ta daha
kararlı ve yapılandırılabilir hale getiren bakım sürümüdür.

## İndir

- **Windows 10/11 x64:** `Grapefruit_0.3.1_x64-setup.exe`
- **Ubuntu/Debian amd64:** `Grapefruit_0.3.1_amd64.deb`

## Öne çıkanlar

- Dönüştürme ve dosya işlemleri için Shift/Ctrl görevlerini değiştiren yeni ayar
- GNOME Extensions tercih penceresi ve uygulama içi tuş ayarları
- Eski File Formatter GNOME uzantısı ve D-Bus adresi için canlı uyumluluk
- Linux ve Windows sistem tepsisi desteği; ana pencereyi açık tutmadan çalışma
- Windows Explorer seçim algılama, çember hover ve bırakma akışı düzeltmeleri
- Tarayıcı, editör ve diğer uygulamalardaki metin seçimlerinin menüyü açmasını
  engelleyen dosya-yöneticisi kaynak filtresi
- Windows release derlemesinde konsol penceresinin gizlenmesi

## Linux kurulumu

```bash
sudo apt install ./Grapefruit_0.3.1_amd64.deb
```

Paket, önceki `file-formatter@io.fileformatter.desktop` kullanıcı uzantısını
yerinde yükseltir. GNOME Shell eski meta veriyi bellekte tutuyorsa uzantı ayar
düğmesi bir sonraki oturum açılışında görünür; uygulama içindeki **Ayarlar**
penceresi hemen kullanılabilir.

## Doğrulama
